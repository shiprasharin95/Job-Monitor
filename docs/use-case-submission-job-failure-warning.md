# Use Case Submission: Job Failure Warning (Batch Jobs)

| Field | Proposed content |
| --- | --- |
| Use Case Description | Proactively monitor SAP batch jobs through SAP Cloud ALM Jobs and Automation Monitoring. Detect elevated aborted and application-error counts, present impacted services and job definitions in a central dashboard, and generate a warning with operational context for the support team. |
| Challenges & Business Drivers | Batch-job failures are often identified late through manual monitoring across multiple managed systems. Operations teams need a centralized warning mechanism, consistent prioritization, and faster triage to reduce business disruption and mean time to resolution. |
| Solutions | A CAP-based Job Failure Warning Agent consumes SAP Cloud ALM job data through a secured SAP BTP Destination. For each failed execution, a grounded SAP AI Core agent produces a short error summary, up to two probable root causes, SAP-documented validation steps, and resolution guidance using only `help.sap.com`. The workflow groups all failed jobs by scheduler and sends one consolidated e-mail per scheduler, for example one e-mail containing five failed-job summaries when five of ten scheduled jobs fail. Individual execution details require the separate SAP Cloud ALM Raw Data Outbound Logs integration (`jam.run` and `jam.run_step`). |
| Benefits | Earlier detection of job failures; centralized operational visibility across services; lower manual monitoring effort; faster incident triage; consistent warning criteria; extensible AI-assisted remediation recommendations. |
| Services & Applications | SAP Cloud ALM Jobs and Automation Monitoring Analytics API; SAP BTP Destination service; SAP BTP Cloud Foundry; SAP CAP Node.js; SAP AI Core / Generative AI Hub with SAP Help grounding; SAP Cloud SDK for AI; SAP Job Scheduling; Microsoft Graph Mail; optional SAP Cloud ALM Raw Data Outbound Logs integration. |
| Prerequisites | SAP Cloud ALM Job and Automation Monitoring configured for target services; Cloud ALM API scope `calm-api.jobs.read`; OAuth2 Client Credentials destination named `CLOUD_ALM_API`; grounded SAP AI Core destination named `JOB_FAILURE_AI_AGENT`; Microsoft Graph destination named `JOB_FAILURE_MAIL` with application permission to send mail; Destination service bound to the CAP app; scheduler name/e-mail and execution-error data available from the job source. For individual execution/error details, configure Raw Data Outbound Logs and an accessible log-storage target. For productive use, protect the application with XSUAA and an approuter. |
| Pipeline Agent Name | Job Failure Warning (Batch Jobs) |
| Business Area | IT Operations - Job and Automation Monitoring |
